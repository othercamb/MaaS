🔧
Prerrequisitos
Verifica tu entorno antes de instalar

Antes de instalar Claude Code Router, asegúrate de tener las siguientes herramientas instaladas y una cuenta activa en Huawei Cloud con acceso a MaaS.

Verificar versiones instaladas
node --version    # Necesitas ≥ 18
npm --version
claude --version  # Claude Code
Si no tienes Claude Code instalado: npm install -g @anthropic-ai/claude-code
Requerimientos de Huawei MaaS
  • Cuenta activa en Huawei Cloud (región Asia-Pacific)
  • Acceso habilitado al servicio ModelArts MaaS
  • API Key de MaaS generada en la consola
  • Al menos un modelo suscrito (GLM-4, Mistral, Llama 3…)
📦
Instalar Claude Code Router
Instalación global via npm

CCR es un proxy local que intercepta los requests de Claude Code y los redirige a Huawei MaaS. Puedes instalarlo globalmente o usarlo con npx sin instalación permanente.

Opción A — instalación global (recomendada)
npm install -g @musistudio/claude-code-router
Opción B — sin instalación permanente (npx)
npx -y @musistudio/claude-code-router start
Verificar instalación
ccr --version
También disponible via Homebrew: brew install claude-code-router
⚙️
Configurar config.json
Define el proveedor Huawei MaaS y las rutas

Este archivo configura los proveedores disponibles y las reglas de enrutamiento. CCR lo busca en ~/.claude-code-router/config.json.

~/.claude-code-router/config.json
{
  "Providers": [
    {
      "name": "huawei-maas",
      "api_base_url": "https://api-ap-southeast-1.modelarts-maas.com/anthropic",
      "api_key": "TU_API_KEY_HUAWEI_MAAS",
      "models": ["glm-4", "mistral-large", "llama-3-70b"]
    }
  ],
  "Router": {
    "default":     "huawei-maas,glm-4",
    "background":  "huawei-maas,glm-4",
    "think":       "huawei-maas,mistral-large",
    "longContext": "huawei-maas,llama-3-70b"
  },
  "ANTHROPIC_BASE_URL": "http://127.0.0.1:3456"
}
Reemplaza TU_API_KEY_HUAWEI_MAAS con tu clave real. Los nombres de modelos deben coincidir exactamente con los suscritos en MaaS.
📝
Configurar settings.json de Claude Code
Apunta Claude Code al router local

Edita el archivo de configuración de Claude Code para que use el router local en vez de la API de Anthropic directamente.

Ruta según sistema operativo
macOS / Linux
~/.claude/settings.json
Windows
%APPDATA%\Claude\settings.json
Contenido del archivo
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "TU_API_KEY_HUAWEI_MAAS",
    "ANTHROPIC_BASE_URL":   "http://127.0.0.1:3456",
    "ANTHROPIC_MODEL":       "glm-4",
    "NO_PROXY":             "127.0.0.1"
  }
}
NO_PROXY=127.0.0.1 evita que proxies del sistema interfieran con la conexión local al router.
🚀
Iniciar el router y Claude Code
Arrancar en el orden correcto

El router debe estar corriendo antes de iniciar Claude Code. Necesitarás dos terminales.

Terminal 1 — iniciar el router
ccr start
Verifica que está activo: curl http://127.0.0.1:3456/health
Terminal 2 — activar variables y arrancar Claude Code
eval "$(ccr activate)"
claude
Para que las variables sean persistentes entre sesiones, agrega eval "$(ccr activate)" a tu ~/.zshrc o ~/.bashrc.
✅
Verificar y usar
Comandos útiles y routing avanzado
🎉
Instalación completa
Claude Code ahora enruta tus requests a través de Huawei MaaS. Revisa los logs del router para confirmar qué modelo está atendiendo cada request.
Comandos dentro de Claude Code
/model huawei-maas,glm-4 Cambiar al modelo por defecto
/model huawei-maas,mistral-large Cambiar a razonamiento avanzado
/model huawei-maas,llama-3-70b Cambiar a contexto largo
Comandos de gestión del router (terminal)
ccr restart Reiniciar tras cambios en config.json
ccr status Ver estado del router
ccr stop Detener el router
ccr activate Exportar variables de entorno a la sesión
Flujo de requests
Claude Code  →  CCR (localhost:3456)  →  Huawei MaaS API
                     ↓
          Routing por tipo de tarea:
          default / background  →  glm-4
          think                 →  mistral-large
          longContext           →  llama-3-70b
