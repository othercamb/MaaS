# MaaS – Guides & Configurations for Huawei Model as a Service

Practical documentation and configuration examples for connecting popular tools to **Huawei Cloud MaaS** (Model as a Service).

These guides help you use Claude Code, Cursor, GitHub Copilot, n8n, Dify, OpenClaw and other clients with Huawei MaaS token services and LiteLLM deployments.

## How to use
1. Pick the guide for the tool you want to connect.
2. Follow the steps (token service / endpoint configuration).
3. Use the Postman files to test the API quickly.
